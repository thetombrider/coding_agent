A coding agent that lives in your terminal.

Give it a prompt and it reads, edits, and runs your code on its own — pausing for your OK before anything risky. Safe by default, cheap by design: the expensive model thinks, a cheap one does the grunt work.

Get started View on GitHub
git clone https://github.com/thetombrider/coding_agent.git && cd coding_agent && ./install.sh

No API key? Try it fully offline first — orin --faux

Where Orin wins

Compared to the closest alternatives — opencode (SST), pi.dev, and Claude Code — Orin makes different trade-offs that pay off in cost, safety, and observability.

BM25 tool pre-filtering per turn

Every turn, a BM25 retrieval pass (via Ratel) ranks the full tool catalog — including MCP tools and skills — and exposes only what's relevant. The expensive model never sees a bloated catalog. Built-in A/B testing measures the impact in your telemetry.

E2B OS-level sandboxing

Most agents enforce safety through permission rules that still run on your host. Orin's sandbox isolation mode runs subagents in E2B ephemeral cloud VMs — a real isolation boundary for untrusted tasks, not a policy.

Shadow-git /undo

Shadow-git snapshots fire before every tool execution — including bash — at the git level. Rollback coverage is broader than competing checkpoint systems, with no known gaps for bash-modified files.

Two-model cost split, at the tool level

delegate_read hands file reads, grep, find, and ls to a cheap model in an isolated call — no write tools, just a distilled summary back. It's wired into the tool set, not a config option, so it happens automatically.

Native OTLP, no plugins

Every turn exports a trace with child LLM spans (model, tokens, cost), tool spans, and subagent spans — readable in Langfuse, Grafana Tempo, Arize Phoenix, or any OTLP backend. Local metrics are always on; content capture stays opt-in.

Offline demo + EU provider

orin --faux runs the full TUI with scripted responses — no API key, no network. Orin also ships Regolo: EU-hosted, OpenAI-compatible, and the only native EU provider option for GDPR-sensitive workloads.

See it in action

Quick start

git clone https://github.com/thetombrider/coding_agent.git
cd coding_agent
./install.sh        # installs Bun if needed, installs deps, builds, links `orin`
orin                 # start the interactive agent

Then add a provider key right from the UI — /providers configure openrouter — and you're off.

Just want to look around first? No key required:

orin --faux         # fully offline, scripted demo

Requirements: Bun ≥ 1.1 (the TUI uses Bun's FFI and a preload transform — plain node won't work), a real TTY, and an OpenRouter key (or another provider) for real use.
