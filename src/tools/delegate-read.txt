Delegate read-heavy work to the cheap model in a single shot. Provide paths and a
question; returns a distilled answer without loading raw file bodies into your context.

Use this when you need to understand or extract information from one or more files —
it keeps the raw content out of your context window entirely.

Prefer this over reading files directly when:
- You need to understand what a file does without reading every line
- You have several files to cross-reference for a single question
- The answer is a summary, not a verbatim quote

Use task (agent: explore) when the scope is open-ended and you need a multi-step
search across the codebase instead.
